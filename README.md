# owner-repo — учебный Telegram-бот

Простой Telegram-бот на **Python** с библиотекой [aiogram 3](https://docs.aiogram.dev/ru/latest/).

Что умеет бот:

| Что вы пишете боту | Что он отвечает |
|---|---|
| `/start` | Здоровается по имени |
| `/help` | Показывает список команд |
| любой текст | Повторяет его обратно |
| фото, стикер и т. п. | «Пока я понимаю только текст» |

## Файлы проекта

| Файл | Зачем нужен |
|---|---|
| `bot.py` | Код бота с подробными комментариями |
| `requirements.txt` | Список библиотек, которые нужно установить |
| `.env.example` | Образец файла с настройками (токеном) |
| `.gitignore` | Файлы, которые git не должен отправлять на GitHub (например, `.env` с секретным токеном) |

## Как запустить бота у себя на компьютере

### Шаг 1. Установите Python

Скачайте Python 3.10 или новее с [python.org](https://www.python.org/downloads/).
На Windows при установке **обязательно отметьте галочку «Add Python to PATH»**.

Проверьте установку в терминале (на Windows — «Командная строка» или PowerShell):

```bash
python --version
```

Должно появиться что-то вроде `Python 3.13.0`. На macOS и Linux команда может называться `python3`.

### Шаг 2. Получите токен бота у @BotFather

1. Откройте в Telegram бота [@BotFather](https://t.me/BotFather). Это официальный бот для создания ботов.
2. Отправьте ему команду `/newbot`.
3. Придумайте **имя** бота (его видят пользователи, например «Мой первый бот»).
4. Придумайте **username**. Он должен заканчиваться на `bot`, например `my_first_test_bot`.
5. BotFather пришлёт **токен**, длинную строку вида `123456789:AAH...`.

> ⚠️ Токен — это пароль от вашего бота. Никому его не показывайте и не выкладывайте на GitHub.

### Шаг 3. Скачайте проект

```bash
git clone https://github.com/gorokhov455-byte/owner-repo.git
cd owner-repo
```

### Шаг 4. Создайте виртуальное окружение и установите библиотеки

Виртуальное окружение — это отдельная папка `.venv`, куда ставятся библиотеки только для этого проекта.

**Windows:**
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

**macOS / Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Если окружение активировано, в начале строки терминала появится `(.venv)`.

### Шаг 5. Вставьте токен

1. Скопируйте файл `.env.example` и назовите копию `.env`.
2. Откройте `.env` в любом текстовом редакторе и замените пример своим токеном:

```
BOT_TOKEN=123456789:AAH...ваш_настоящий_токен
```

### Шаг 6. Запустите бота

```bash
python bot.py
```

Если в терминале появилось «Бот запущен», откройте своего бота в Telegram и нажмите **Start**.

Чтобы остановить бота, нажмите в терминале `Ctrl+C`. Пока программа работает, бот отвечает, а когда она остановлена — молчит.

## Частые ошибки

| Ошибка | Что делать |
|---|---|
| `Не найден BOT_TOKEN` | Нет файла `.env`, или в нём опечатка. Проверьте шаг 5. |
| `ModuleNotFoundError: No module named 'aiogram'` | Не активировано окружение или не установлены библиотеки. Повторите шаг 4. |
| `TelegramUnauthorizedError` | Неверный токен. Скопируйте его у @BotFather ещё раз. |
| `'python' не является внутренней или внешней командой` | Python не добавлен в PATH. Переустановите его с галочкой «Add Python to PATH». |
